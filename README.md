# Grundwortschatz 2000

Vokabeltrainer Englisch ⇄ Deutsch mit Karteikasten und Hörmodus.

App öffnen: https://wolfgangmockel-del.github.io/vokabeltrainer-/

Auf Android in Chrome öffnen und über das Menü „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ wählen.
Der Lernstand wird pro Person auf dem jeweiligen Handy gespeichert.

Die Vokabelliste steht auch als `vokabeln.csv` (Englisch;Deutsch;Seite) im Repository.
