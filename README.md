# Vokabeltrainer

Vokabeltrainer mit Karteikasten und Hörmodus für drei Sprachen, jeweils mit Deutsch:

- **Englisch:** Grundwortschatz 2000 (1796 Einträge)
- **Kroatisch A2:** 1200 Vokabeln und 300 Redewendungen
- **Spanisch A2:** 1200 Vokabeln und 300 Redewendungen

App öffnen: https://wolfgangmockel-del.github.io/vokabeltrainer-/

Auf Android in Chrome öffnen und im Menü „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ wählen.
Der Lernstand wird pro Person und pro Sprache auf dem jeweiligen Handy gespeichert.

Für Kroatisch und Spanisch braucht das Handy die passende Stimme der Google Sprachausgabe
(Einstellungen → System → Sprache & Eingabe → Sprachausgabe → Sprachdaten installieren).

Die Vokabellisten liegen auch als CSV im Repository: `vokabeln.csv`, `vokabeln-hr.csv`, `vokabeln-es.csv`.
